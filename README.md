# Atividade 05: Site de paternidade

## Sobre a Atividade:

A atividade proposta pelo professor teve como objetivo desenvolver um site utilizando os recursos e conceitos apresentados em sala de aula. Durante a criação, pude colocar em prática os novos comandos aprendidos, explorando a estilização dos elementos para construir uma página organizada e mais estilizada.

## O que aprendemos em aula 📢

Durante a aula 04, estudamos e aplicamos conceitos importantes para o desenvolvimento de páginas web, entre eles:

- Dividir nosso código em sessões, utilizando o div, header, main e footer;
- Avançamos em tags para estilizar nossos sites;
- Criamos identificadores para estilizar individualmente cada parte do nosso código, utilizando "class".

O principal objetivo deste projeto foi botar em prática e memorizar os conhecimentos apresentados durante a aula, sem a ajuda do professor. Ao desenvolver o site, tivemos a oportunidade de experimentar os recursos aprendidos, compreender melhor sua aplicação e identificar como cada elemento trabalha na construção dosnossos sites.
